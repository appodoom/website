About DerboukaGPT

DerboukaGPT is a joint effort by three undergraduate students, a computer science professor, and a professional percussionist to bring Eastern percussion into the age of modern artificial intelligence.

We are building the first Large Eastern Percussion Model, focused on the derbouka, exploring how transformer architectures can learn and generate its complex rhythmic language.

This site features an interactive demo, a musician-tailored generation tool for producing human-like percussion from custom settings, and a rating platform where users can evaluate generated outputs to support ongoing development.

Source Code

DerboukaGPT is an open source project. All model architecture, training tools, dataset utilities, and the website itself are available publicly for anyone interested in exploring or contributing to the development of Large Eastern Percussion Models.

The full repository is available on GitHub. Model releases and datasets will also be published soon on Hugging Face.
